## 🚀 Local Setup (Windows Ecosystem)
If you'd like to run the website locally on a Windows machine to contribute, test changes, or build upon our tools:

1. **Install Ruby and Jekyll:**
   Download and install [Ruby+Devkit for Windows](https://rubyinstaller.org/).
   Open your Command Prompt or PowerShell and install Jekyll and Bundler:
   ```cmd
   gem install jekyll bundler
   ```

2. **Clone the Repository:**
   ```cmd
   git clone https://github.com/deepstratAI/deepstratai.com.git
   cd deepstratai.com
   ```

3. **Install Dependencies:**
   ```cmd
   bundle install
   ```

4. **Serve the Site Locally:**
   ```cmd
   bundle exec jekyll serve
   ```
5. Open `http://localhost:4000` in your web browser.
